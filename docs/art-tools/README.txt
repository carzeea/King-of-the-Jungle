Scripts that generated the title-screen Lion's crown and J belt medallion.
metal.py    shared gold renderer (heightmap -> lighting, gems, pearls)
crown2.py   renders crown2.png (polished gold, velvet cap, gems, pearls)
buckle.py   renders buckle_J.png (gold disc with raised J)
compose.py  places both on the cut-out Lion:  python3 compose.py 652 52 196 13
            (crown center x, center y, width, tilt in degrees)
